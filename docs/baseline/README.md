# Baseline Snapshots

This folder stores immutable baseline snapshots for AI review and change governance.

Rules:
- Baseline snapshots are generated by build profile `baseline-sync`.
- Do not manually edit snapshot files under `docs/baseline/snapshots`.
- Authoring remains in original source locations such as `docs/` and approved governance files.
- Change requests must copy from the active baseline pointer.

Key files:
- `active_baseline.json`: points to the approved baseline snapshot.
- `snapshots/<baseline_id>/manifest.json`: checksum and file inventory.
