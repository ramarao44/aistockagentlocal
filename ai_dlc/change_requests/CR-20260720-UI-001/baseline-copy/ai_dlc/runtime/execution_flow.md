# EXECUTION FLOW

1. Human updates PSC or Human Intent (or defect/CR input).
2. HIR validates against PSC and emits decision.
3. PL approves FIS for accepted intents.
4. AA produces governed specs.
5. DEV implements approved bolts.
6. QA validates with governed tests.
7. OPS validates runtime readiness.
8. DOC publishes governed docs.
9. DME updates traceability and drift report.
10. CCS validates protected changes and final lineage.
