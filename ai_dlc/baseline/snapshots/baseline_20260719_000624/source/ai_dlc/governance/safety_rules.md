# SAFETY RULES

1. Human Intent is interpreted as requirement input, not destructive operation.
2. Existing implemented features are never removed unless explicit governed removal request exists.
3. No role may edit artifacts outside its ownership boundary.
4. Protected artifacts require CCS approval and audit log.
5. FIS changes require HIR decision plus PL approval.
6. Scope expansion requires explicit scope expansion ticket.
7. Any ambiguity must create clarification ticket, not implicit assumption.
